Synthèse budgétaire — prévu / réalisé / écart

Prévu = budget prévisionnel (F5). Réalisé = dépenses (F1) sur la période de la session{% if data.debut %} ({{ data.debut }} → {{ data.fin }}){% endif %}. Écart = Prévu − Réalisé.
{% endblock %} {% block aide %}
Aide — Synthèse budgétaire
  • Prévu : somme des lignes du budget prévisionnel (F5) pour la session.
  • Réalisé : dépenses de trésorerie (F1) datées dans la période de la session ({{ data.debut }} → {{ data.fin }}).
  • Écart = Prévu − Réalisé : positif = sous-consommé ; négatif = dépassement (en rouge).
  • Par formation : prévu seul — la trésorerie (F1) ne porte pas la formation, le réalisé n'y est pas ventilable.
  • Les écarts alimentent les plans d'action (suivi des dépassements et sous-consommations).
