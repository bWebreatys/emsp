Aide — Curation de la nomenclature

Trois ecrans pour la nomenclature : Nomenclature budgetaire (codes) = ajouter / corriger un code ; Nomenclature — curation (cet ecran) = activer / desactiver en masse ; Parametres & listes = les autres listes de reference. Ici on cure ; pour creer un code, passez par l'ecran des codes.

  • Actif = Oui : le code est proposé à la saisie d'un mouvement (F1) ou d'une ligne de budget (F3).
  • Actif = Non : code en réserve (socle OHADA), masqué de la saisie jusqu'à activation.
  • Cochez plusieurs lignes puis Activer / Désactiver la sélection pour curer vite.
  • Pour ajouter un sous-article ou corriger un intitulé, utilisez l'écran Nomenclature budgétaire (codes).
