Aide — Cloture & archivage
  • Cloture des eleves (annee scolaire, oct → juil) : journalise les eleves sortis (Diplome / Abandonne / Radie). Ils restent dans le fichier actif environ {{ cfg.ANNEES_GARDE_ELEVES }} ans, puis sont archivables.
  • Archivage : deplace les cohortes sorties depuis ≥ {{ cfg.ANNEES_GARDE_ELEVES }} ans vers un fichier d'archive separe et renseigne la reference dans le journal.
  • Cloture compta (annee civile) : archive les mouvements de l'annee, ecrit le journal permanent, et reporte a nouveau le solde de chaque compte (1re ligne de l'exercice suivant).
  • Le proces-verbal est consultable / imprimable (PDF via le navigateur) et telechargeable en Word.
