Aide — Impressions

Point central d'impression. Cet ecran est le hub de toutes les editions. Les boutons d'impression presents sur les autres ecrans (liste, attestation, recu, tableau de bord…) sont des raccourcis vers les memes editions — pas de double emploi.

Chaque bouton ouvre un apercu imprimable dans un nouvel onglet. Sur l'apercu : le contenu est retouchable a la main (modifications ponctuelles, non enregistrees), puis bouton Imprimer / PDF (impression papier ou PDF du navigateur).

Les parties fixes (en-tete, titre, corps type, mentions, signataire, nombre de copies) se reglent durablement dans Parametrages → Modeles de documents.
