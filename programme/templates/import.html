Aide — Import
  • Collez le contenu du CSV national. Colonnes attendues dans l'ordre : Matricule, Genre, Nom, Prenom, Date naissance, Lieu naissance, Niveau/Filiere. Separateur tabulation, ; ou , (auto-detecte) ; une ligne d'en-tete est ignoree.
  • La colonne Statut vs base compare le matricule a la fiche etudiants : NOUVEAU = absent (a ajouter), EXISTANT = deja present.
  • Recopiez ensuite uniquement les NOUVEAU dans la fiche etudiants (saisie A1). Cette zone ne modifie jamais la fiche etudiants : aucun risque sur les donnees.
  • Retour en arriere : un import ou un vidage peut etre annule (restauration de la version precedente) tant que vous n'avez pas relance une autre action.
