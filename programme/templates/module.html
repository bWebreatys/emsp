Aide — {{ info.libelle }}
{% if onglet == 'P0_Parametres' %}

Renseignez ici toutes les listes de reference. Commencez par cet onglet : toutes les listes deroulantes des autres pages en dependent.

{% elif onglet == 'A1_Etudiants' %}

Le matricule est la cle qui relie l'etudiant a toutes les autres pages : ne le modifiez pas apres saisie. Completez genre et origine s'ils manquent dans le CSV national.

{% elif onglet == 'A2_Presences' %}

Une ligne par etudiant, par seance et par creneau (10h, 12h, 15h, 17h). Pas d'absence partielle en V1.

{% elif onglet == 'A3_Sessions' %}

Une seance = un creneau hebdomadaire recurrent (matiere, enseignant, salle, jour, horaire). L'enseignant se choisit dans la liste des fiches Enseignants & vacataires (E1) — renseignez E1 d'abord, sinon la liste est vide. La salle (facultative) se choisit dans la liste des Salles (L1). Plus de saisie libre : on evite les fautes de frappe et on garantit les liens Seances ↔ formateurs et Seances ↔ salles. Une seance saisie apparait aussitot dans le calendrier et le planning des salles.

Trois vues des memes seances : Seances & planning (cet ecran) est la saisie de l'emploi du temps ; le Calendrier en est la vue mois / semaine / jour ; Seances realisees (exceptions) ne sert qu'a enregistrer les ecarts (remplacant, cours annule, duree). On saisit ici, on consulte au calendrier, on note les exceptions a part.

{% elif onglet == 'A4_Documents_etud' %}

Registre des documents remis aux etudiants (attestations de passage, bulletins, releves). Le Statut suit le cycle de validation : En attente conseil → En attente delai (contestation : 1 semaine) → Imprimable → Remis. Le statut et les dates sont saisis a la main ; la generation PDF et le passage automatique en imprimable sont des pistes possibles ensuite, sans engagement.

{% elif onglet == 'S1_Stages' %}

Une ligne par affectation de stage (6 seances/an, 1 mois chacune). Le lieu provient de la liste des etablissements (Parametres) ; renseignez-la d'abord si elle est vide. Fiche retour passe a O quand l'etablissement renvoie la fiche. Une note /20 et une observation libre suffisent ; la grille d'appreciation detaillee et la gestion fine des plaintes sont des pistes possibles ensuite, sans engagement.

Trois ecrans pour les stages : Stages — affectation & fiches retour (cet ecran) est l'ecran de travail (saisie d'une affectation et de la fiche retour) ; Stages — affectation propose une repartition automatique a ajuster ; Stages — suivi & tableau de bord est la vue de pilotage (lecture). Parcours conseille : proposer (auto) → ajuster / saisir ici → suivre.

{% elif onglet == 'E1_Enseignants' %}

Une fiche par enseignant ou vacataire. Le matricule est la cle qui relie l'enseignant au releve des heures (E2) et, plus tard, aux seances. Si le matricule officiel n'existe pas encore, gardez le code provisoire NC-<n> propose automatiquement (NC-1, NC-2…) : il distingue chaque enseignant et sera remplace par le vrai matricule le jour ou il est connu. Renseignez Titulaire ou Vacataire ; les matieres enseignees peuvent etre listees dans un seul champ.

{% elif onglet == 'L1_Salles' %}

Creez ici vos salles : un ID salle court (pre-rempli en SAL-<n>, modifiable) et un nom explicite (ex. « Amphi A », « Labo TP 1 »). Choisissez le type (Amphitheatre, Cours, TD, TP… — la Direction peut completer la liste dans Parametres). Indiquez la capacite, les equipements (separes par ;) et le batiment. Les salles saisies alimentent le planning des salles, la fiche salle, et deviennent selectionnables par les seances.

Au deploiement : renseignez ce referentiel des salles en premier. Tant qu'il est vide, le planning derive les salles des noms presents dans l'inventaire materiel (M1) ; une fois L1 saisi, les salles ont une source unique et un descriptif complet (type, capacite, batiment).

{% elif onglet == 'E2_Releve_heures' %}

Un releve par enseignant et par periode de paie. L'enseignant se choisit dans la liste E1 (affichee « Matricule — Nom Prenom » ; c'est le matricule qui est enregistre). Indiquez le Mois / Annee (format MM/AAAA), le volume programme (optionnel) et le volume constate (obligatoire). Le Total heures a payer est calcule automatiquement : il reprend les heures constatees (heures seulement, sans taux) — colonne calcul, non saisissable.

Deux chemins pour les heures : ce Releve des heures est l'ecran de saisie manuelle (par enseignant et periode) ; l'ecran Heures constatees (report paie) peut reporter automatiquement les heures calculees a partir des seances realisees. Si le report automatique est disponible, utilisez-le ; sinon, saisissez ici.

{% elif onglet == 'F2_Comptes' %}

Un compte ou une caisse par ligne (ne pas dupliquer un compte). Choisissez le Nom du compte dans la liste (memes noms que F1, pour que le solde se calcule), le Type (Banque / Caisse / Autre) et le Solde initial (KMF). Le Solde courant se met a jour tout seul : solde initial + recettes − depenses du compte (d'apres la tresorerie F1) — colonne calcul, non saisissable. Renseignez d'abord la liste Comptes_caisses dans Parametres. Acces : Comptabilite et Direction.

{% elif onglet == 'F1_Mouvements' %}

Une ligne par mouvement de tresorerie (KMF). Renseignez le Sens (Recette / Depense), la Categorie (la liste reunit recettes et depenses), le Compte / caisse et un Libelle. Saisissez le montant dans la colonne correspondant au sens : Recette ⇒ Montant Recette, Depense ⇒ Montant Depense (l'autre doit rester vide ; controle automatique). La Date operation est pre-remplie au jour ; Saisi par est rempli automatiquement avec votre identifiant. Indiquez le bailleur (source de financement) pour la tracabilite AFD.

Avant de saisir : la Direction / Comptabilite doit d'abord renseigner dans Parametres les listes Cat_Recettes, Cat_Depenses et Comptes_caisses (et, si utilise, Postes_budgetaires), sinon les listes deroulantes obligatoires sont vides. Acces reserve : Comptabilite et Direction (Acces financier = O).

{% elif onglet == 'L2_Reservations' %}

Reservez une salle en dehors des cours (reunion, examen, evenement, partenaire). Choisissez la salle (liste L1), la date et les heures, indiquez qui reserve et le motif. Le Statut (Demandee / Confirmee / Annulee) suit la demande. Contrairement aux seances (emploi du temps hebdomadaire recurrent), une reservation est datee et ponctuelle : c'est pour cela qu'elle est geree a part. La vue d'occupation d'une salle reunira les cours et ces reservations.

{% elif onglet == 'M1_Equipements' %}

Inventaire de pilotage des equipements (sans maintenance : pannes, contrats et pieces detachees relevent du futur GMAO, hors perimetre). Une ligne par equipement : designation, categorie, salle / localisation (liste L1), date d'acquisition, bailleur (AFD, Etat… liste partagee avec la tresorerie), montant, rappel de la piece F1 liee, etat et n° d'inventaire. Permettra de sortir, par exemple, les equipements finances par l'AFD et leur localisation.

Circuit depense → equipement : le montant, le bailleur et la reference de piece proviennent de la comptabilite (depense F1), pas de l'inventaire. Pour une fiche complete : enregistrez d'abord la depense en tresorerie (F1), puis reportez ici sa reference de piece F1. Une fiche sans ces champs reste valable pour le pilotage, le lien compta etant alors a completer a la main.

{% elif onglet == 'IMPORT_zone' %}

Collez le CSV national. La colonne Statut vs base indique NOUVEAU ou EXISTANT : ne recopiez dans la fiche etudiants que les lignes NOUVEAU.

{% elif onglet == 'R1_Maquettes' %}

Referentiel des formations (consultation). Reprend les maquettes officielles des 5 filieres : pour chaque UE / module et chaque matiere, le volume horaire (CM / TD / TP / total), le credit (ECTS) et le coefficient, par niveau et semestre. Il sert de socle : choix des matieres dans les seances, volume horaire programme pour le suivi des heures, et structure UE pour les relev(e)s de notes. Page en lecture seule (filtrable et exportable en Excel).

{% elif onglet == 'N1_Bareme_UE' %}

Le barème de référence pour le calcul des moyennes : pour chaque filière / niveau / semestre, les UE, leurs matières, leur coefficient et leurs ECTS. La moyenne du semestre est la moyenne des UE pondérée par le coefficient ; renseignez ce barème avant toute saisie de notes.

Barème provisoire : seul le barème L2 Soins infirmiers est confirmé (coefficients réels, colonne Coef confirmé = Oui). Pour les autres filières, la structure UE/matières est reprise des maquettes mais le coefficient est à 1 par défaut (Coef confirmé = Non) : il devra être corrigé d'après le document de référence officiel pour que les moyennes soient conformes aux exigences de passage. Tant que Coef confirmé = Non, le relevé porte la mention « barème provisoire ».

{% endif %}
