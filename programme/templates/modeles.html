Aide — Modeles

Trois ecrans autour des documents : Modeles de documents (cet ecran) = les gabarits reutilisables ; Bibliotheque documentaire = l'archivage de fichiers ; Impressions & editions = la generation des editions. Ici on prepare les gabarits.

Modifiez ici l'en-tete, le titre, le corps type, les mentions/pied, le libelle du signataire et le nombre de copies de chaque document. Ces reglages sont persistants (enregistres dans le classeur).

Dans le corps, les jetons entre accolades (ex. {nom}, {date_jour}) sont remplaces automatiquement a l'impression par les donnees reelles. Les jetons disponibles sont rappeles sous chaque corps. Une retouche ponctuelle reste toujours possible directement sur l'apercu avant impression.

Lancer les impressions : Finances & pilotage → Impressions & editions.
