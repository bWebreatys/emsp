│     └─ ✅ pip install -r requirements.txt                                │

│     └─ ✅ Changer port app.py ou fermer autre app                        │

│     └─ ✅ Modifier app.py: host='0.0.0.0'                                │
│                                                                           │
│  ❌ "Permission denied" (Linux)                                           │
